# My Favorite Mushrooms

This project was made as part of my course at Hyper Island to learn CSS Responsive Web Design.

**Live site:** [my-fav-mushrooms.netlify.app](https://my-fav-mushrooms.netlify.app/)

## Overview

This is a front-end website about mushrooms. It is designed to be easy to browse, with a clean presentation that can be expanded with additional species, facts, images, and educational content.

## Features

- A dedicated website focused on mushrooms
- Clear, beginner-friendly content structure
- Responsive layout for desktop and mobile browsers
- Static deployment through Netlify
- A lightweight project that can be customized or extended easily

## Getting started

If you have the source files locally, you can run the project by opening the main HTML file in a browser.

```bash
# Clone your repository
 git clone <your-repository-url>

# Enter the project folder
cd <your-project-folder>

# Open index.html in your browser
```

For local development with automatic browser refresh, you can use a lightweight local server such as the VS Code Live Server extension.

The website is deployed with Netlify and is available at:

[https://my-fav-mushrooms.netlify.app/](https://my-fav-mushrooms.netlify.app/)



## Important note

This website is intended for educational and visual purposes. Never use a website alone to identify wild mushrooms for consumption. Consult qualified local experts and multiple reliable identification sources before handling or eating any wild mushroom.
